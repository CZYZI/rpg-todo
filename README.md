# ⚔️ RPG 待办冒险

> 把你的待办事项变成 RPG 冒险任务，积分系统 + 皮肤商店，每天打怪升级！

## 🌐 在线体验

👉 **[点击开始冒险](https://CZYI.github.io/rpg-todo/)**

## ✨ 功能特色

- 🏰 **三大世界观** — 中世纪奇幻 / 赛博朋克 / 现代冒险，自由切换
- ⚔️ **任务 RPG 化** — 每个待办自动生成专属冒险描述（击杀怪物、探索场景）
- 📊 **积分系统** — 完成任务得 XP，连击加成×1.2，每日登录 +50 XP
- 🛒 **兑换商店** — 积分兑换主题皮肤、角色皮肤、道具
- 🔥 **连击机制** — 连续完成任务触发连击，连击≥3 自动加成
- 📥 **批量导入** — 支持文本粘贴 / TXT / CSV 文件批量导入任务
- 💾 **本地持久化** — 数据存储于 localStorage，刷新不丢失

## 🚀 快速使用

无需安装，直接打开 `index.html` 或访问 GitHub Pages 即可。

## 📦 项目结构

```
rpg-todo/
├── index.html          # 完整单文件应用（无需构建）
├── src/                # React 版源码（可选）
│   ├── App.jsx
│   ├── App.css
│   └── main.jsx
├── .github/
│   └── workflows/
│       └── deploy.yml  # GitHub Pages 自动部署
└── package.json
```

## 🎮 使用说明

1. 选择世界观（奇幻 / 赛博朋克 / 现代）
2. 输入待办事项，点击「生成任务 ⚔️」
3. 设置预估耗时和难度系数（影响 XP 奖励）
4. 完成任务点击「✅ 完成」获得积分
5. 积分可在商店兑换各种皮肤和道具
